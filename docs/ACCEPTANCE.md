## Delivered foundation

Economics/trade aliases and scalar structured filters, local keyword/BM25 retrieval, stored findings, comparisons, explicit/suggested relationships, graph controls, review inbox and lifecycle tools. Nine compiled categories supported: Literature, Topics, Datasets, Policies, Methods, Theories, Analyses, Comparisons, Queries.

Country/product/method/evidence filters match declared scalar metadata exactly. The restricted parser supports one-line lists for ordinary metadata, but structured filters are not a geography ontology or classification-concordance engine. Missing fields are not inferred. Economics evidence labels and required identification metadata improve recording, not scientific validity.

Separate country/product scalar fields used by filters should be populated deliberately; plural country/product lists can remain descriptive metadata. No inferred equivalence between different codes or classification editions.

Template/schema/prompt set covers theory, identification, publication versions, datasets/vintages, policy timing, located findings, actual analysis provenance and bounded review. English/Korean guides explain setup delegation and ongoing integration.
