# Recent shared upgrades from the Hematology construction kit

These are reusable software changes adapted to economics. No medical research collection, personal agent assignment, credentials, notebooks or live vault configuration is exported.

## Readable records, compact entity chooser

Entity controls use compact name/count entries. Full sample titles are available under collapsed previews, rather than filling the top of the screen. Entity pages retain readable full document titles, stored summaries/scope/findings, citation/version/review information and explicit wiki/source/original actions. Information is taken from existing records, never generated to fill a card.

Existing economics filters, personalized entity navigation, evidence inventories and topic-proposal workflows remain. Theory, datasets, policies, methods and analyses are not turned into clinical-study records.

## Recent-first viewing

Blank browsing and entity lists default to recent recorded publication date; keyword searches retain relevance. Role grouping remains where applicable. A sort selector permits chronological or title order.

Use valid publication_date/published/date_published, then publication_year/year. Keep year/month/day precision; undated documents sort last with stable title/path ties. No modification/intake/created timestamp or filename/title year is substituted.

If publication fields are absent and recorded version has exactly one unambiguous plausible year, show **Version/edition year** and use it as a chronology fallback, explicitly stating publication date is unverified. Conflicting edition/publication years stay unestablished. No source metadata is rewritten.

## Optional Gemini Notebook export

Select records, choose wiki summaries or explicitly permitted stored PDFs, choose an existing notebook or new title, preview exact content/destination and confirm rights/privacy before upload. No cloud action occurs just by opening the panel. Backend uses an optional unofficial notebooklm-py adapter and isolated authentication/private receipts.

Original files stay unchanged. Per-source processing is read back; partial or uncertain outcomes are not complete success. No automatic sharing/deletion/whole-wiki sync, no copy of another person's account, and no automatic enrollment of a personal collector. Setup/sign-in and a bounded authorized live test remain separate from code publication.

Private plugin settings: repositoryPath, notebookPythonExecutable, notebookStateDir. Install the optional Python client in a separate environment; sign in personally with NOTEBOOKLM_HOME set to the configured state directory's auth subfolder and NOTEBOOKLM_PROFILE=default. Do not import browser cookies or share passwords in chat. Scope of PDF selection is explicit Sources → safe stored raw_path, not arbitrary restricted-data folders.

## 한국어

혈액학 위키의 공통 개선을 경제학에 맞추어 적용합니다. 개체 선택기는 이름·건수와 접힌 미리보기로 간결하게 유지하고 문서 카드는 전체 제목·저장된 요약·출처·원문 연결을 보존합니다.

기본 열람은 최근 출판일 우선, 검색은 관련도 우선입니다. 출판일이 없고 판 정보에 단일 연도가 명확하면 ‘판 연도—출판일 미확인’으로 구분하여 정렬합니다. 날짜나 과학적 내용을 만들어내지 않습니다.

Gemini Notebook 전송은 선택한 자료·대상 노트북·내용을 먼저 확인하고 권한·개인정보 동의 후에만 실행합니다. 원문 이용 권한이 Google 업로드 허락을 자동 뜻하지 않습니다. 실제 계정·노트북·개인 수집 에이전트 설정은 이 저장소에 포함하지 않습니다.
