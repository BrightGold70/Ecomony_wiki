# Relationship navigation: paper, source and original file

## Use the right destination

- **Open wiki note** opens the stored study/topic/data/method record in a split, retaining the dashboard.
- **Open source record** opens citation, access and version provenance.
- **Open stored original PDF** opens an explicitly recorded, existing PDF inside the wiki's raw storage. It does not guess original files from names.
- An explicit DOI/source webpage action opens a safe recorded web address; it may require institutional access. No automated full-text download or access bypass occurs.

Choose a graph node to show its full title and actions above the map. Double-click/Enter opens its wiki note; Space selects for inspection. Both ends of recorded relationships and each related-document card offer direct opening actions.

The full network includes isolated matching records by default. **Linked notes only** deliberately hides isolated records without inventing links. Clear graph keywords and structured filters to restore the full authorized indexed collection. Counts distinguish displayed/matching records and isolated records. The nine supported compiled categories are searchable; Sources and original PDFs are provenance destinations, not duplicate paper nodes.

Country/product/method/evidence filters use declared metadata. They do not infer that records share a dataset, estimand, classification edition or causal interpretation. Lexical similarity remains a suggestion, not corroboration or independent evidence.

## Missing originals and safety

A note may offer only its source record. Missing original files or publisher links stay explicit; no arbitrary private-folder lookup or shell command is executed. Original-PDF actions require a safe raw_path in a source and an existing file. Traversal, hidden/private paths, detectable symlinks and unsafe protocols are rejected.

This is a construction-kit feature. Automated harness tests verify paths/actions; native Obsidian deployment must be checked in your own prepared economics vault. No personal research collection is installed by cloning the repository.

## 한국어

관계 지도의 노트를 선택하면 지도 위에 제목과 열기 버튼이 나타납니다. **Open wiki note**는 위키 기록, **Open source record**는 출처·버전 기록, **Open stored original PDF**는 실제 연결된 로컬 PDF입니다. 더블클릭·Enter는 위키 노트를 분할 화면으로 열고, Space는 선택하여 내용을 확인합니다.

연결이 없는 기록도 기본 지도에 표시됩니다. **Linked notes only**를 켜면 연결된 기록만 표시합니다. 전체를 보려면 검색어와 국가·품목·방법·근거 필터를 해제하세요. 원본 연결이 없으면 임의로 찾지 않습니다. 출판사·DOI는 별도의 외부 이동이며 접근 권한이 필요할 수 있습니다. 연구 유사성은 인과성·합의·독립 재현의 증명이 아닙니다.
